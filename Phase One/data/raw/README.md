# Raw Data and Generated Inputs

Per the Qiskit Fall Fest 2026 Phase 1 Master Guide, all benchmark inputs are self-contained and programmatically generated. No external downloads are required.

This directory stores:
- Baseline Hamiltonian parameters (TFIM coupling `J = 1.0`, transverse field `g = 1.0`, initial state `|0000>`)
- Raw simulation trajectories and measurement shot records from Qiskit `AerSimulator`
- Seed configurations and raw processor topology mappings
