In Phase 1 many teams raised clarification questions because some inputs and definitions were left open: which boundary condition, which observables, which time window, how fidelity is measured, and what the processors are. The 24-hour offline round leaves no time for that, so the problem statements were reviewed by subject experts and every open point is now fixed in this document.
Where this document gives a number, a convention or a definition, use it exactly. It supersedes the Phase 1 wording. The tasks themselves are unchanged in spirit; they are now precise enough that every team measures the same thing and judging is fair.

4. Processors A, B and D
Processor definitions
Processor A — 5 qubits, coupling edges (0,1), (1,2), (1,3), (3,4). A tree: it contains a 4-qubit line but no 4-qubit cycle.
Processor B — 9 qubits, coupling edges (0,1), (1,2), (1,6), (2,3), (2,6), (2,5), (3,4), (4,5), (5,6), (6,7), (6,8), (8,0).
Processor D — your own design (Section 6), at most 12 qubits.
Edges are undirected. A and B use the official basis and noise model, so differences come from connectivity alone. Required rows use these maps; your Phase 1 variants may appear as additional experiments.
Capacity rule. A circuit that needs more qubits than a processor has is not run on it: enter "not executable: needs N qubits, has M" and explain the limit. This only applies to the optional N = 6 tier of PS-S1 on Processor A.

5. Objective 1 — Bell-state preparation and verification
Prepare |Φ⁺⟩ = (|00⟩ + |11⟩)/√2 with H on the first qubit and CX from the first to the second, on Processor D.
Run on one pair of directly connected qubits and on the pair of qubits farthest apart in your D graph. Report the physical qubits.
For each pair, run ideal and noisy, measuring XX, YY and ZZ with 4,096 shots each (12 circuits).
Basis changes: ZZ none; XX: H on both; YY: S† then H on both. Ideal values ⟨XX⟩ = +1, ⟨YY⟩ = −1, ⟨ZZ⟩ = +1.
⟨P⟩ = (N_even − N_odd) / N,      SE(⟨P⟩) = √((1 − ⟨P⟩²) / N)
F = (1 + ⟨XX⟩ − ⟨YY⟩ + ⟨ZZ⟩) / 4,      SE(F) = ¼ √(SE_XX² + SE_YY² + SE_ZZ²)
This is exact for |Φ⁺⟩; P(00) + P(11) is not accepted as a fidelity. bell_experiment(processor, pair, noisy) runs the procedure. Report bell.csv and explain in 3–5 sentences why the noisy fidelity drops and why the distant pair is worse.

8. PS-S1 — Ising model ground state and phase change
Problem
Prepare the ground state of the open-chain transverse-field Ising model with VQE across the change from the ordered phase (small g, spins aligned along Z) to the disordered phase (large g, spins along X), and show which observables reveal the change and how deep the ansatz must be. At finite N the transition near g = 1 is smooth, which is why a range of g is used.
Locked data
Item
Value
Hamiltonian
H = −Σᵢ ZᵢZᵢ₊₁ − g Σᵢ Xᵢ, open chain, J = 1
Sizes
N = 4 (required); N = 6 (optional tier, bonus)
g values
0.25, 0.50, 0.75, 1.00, 1.25, 1.50, 2.00 (7 values)
Files
data/s1/tfim_open_N<N>_g<g>.json, with exact E0_exact and E1_exact
Method
VQE only (QPE is not part of this problem)
Recommended ansatz: Hamiltonian Variational Ansatz (HVA)
Start in |+⟩^N, then repeat L layers of [a ZZ layer exp(−iγₗ/2 Σ ZᵢZᵢ₊₁) on all bonds, then an RX(βₗ) layer on all qubits]. Two parameters per layer, it follows the Hamiltonian, keeps the spin-flip symmetry, and its bonds map directly onto a line of qubits. hva_ansatz(N, L) builds it. Other ansätze are allowed if justified.
Observables
Observable
Definition
What it shows
Transverse magnetization
m_x = (1/N) Σᵢ ⟨Xᵢ⟩
Grows from ≈ 0 to ≈ 1 as g increases
Nearest-neighbour correlation
C_zz = (1/(N−1)) Σᵢ ⟨ZᵢZᵢ₊₁⟩
≈ 1 in the ordered phase, falls in the disordered phase
Squared magnetization
⟨M_z²⟩/N², with M_z = Σᵢ Zᵢ
Order parameter that survives at finite N
Mean ⟨σz⟩ (diagnostic)
⟨M_z⟩/N
Exactly 0 in the true ground state by symmetry. A non-zero VQE value means the ansatz broke the symmetry — report and explain it
Tasks
Exact references. Diagonalise H for every g and compute E₀, E₁ and the four observables.
VQE across g. For every g, run VQE with seeds 0, 1, 2. Report the best energy, energy error, the four observables, fidelity F = |⟨E₀|ψ⟩|² and F₂ = |⟨E₀|ψ⟩|² + |⟨E₁|ψ⟩|², optimizer calls and number of parameters (s1_results.csv). F₂ matters at small g, where E₀ and E₁ are almost degenerate.
Layer study. Find the smallest number of layers L that reaches |energy error| < 10⁻³ at each g, and explain why the ordered side needs more depth.
Phase plot. Plot m_x, C_zz and ⟨M_z²⟩/N² against g, VQE against exact, and say which observable shows the change most clearly.
Noisy run on Processor D. For your converged circuits at g = 0.5, 1.0 and 2.0, compute the observables and energy from the noisy density matrix (noisy_expectations()) and the noisy fidelity (s1_noisy.csv).
Architecture. Report resource metrics on A, B and D for your final ansatz, and explain how the processor supports its entangling pattern.
How PS-S1 is scored (inside Objective 3)
Energy error and F/F₂ across all g
Correct observables, including a correct reading of the ⟨σz⟩ diagnostic
Layer study and phase-plot interpretation
Noisy results and resource comparison; N = 6 tier as a bonus
9. PS-S2 — Real-time dynamics and Trotter error
Problem
Simulate a quench: start in the Néel state and evolve under the transverse-field Ising model. Measure how the Trotter step count controls accuracy and cost, show the error scaling on a log-log plot, and compare two ways of building the ZZ interaction on different hardware.
Locked data
Item
Value
Hamiltonian
Open chain, N = 4, J = 1, g = 1 (data/s2/tfim_open_N4_g1.00.json)
Initial state
Néel: Zᵢ = (−1)ⁱ, i.e. |↑↓↑↓⟩, Qiskit label 1010
Time grid
t = 0, 0.25, 0.50, …, 4.00 (17 points)
Steps for the curves
n = 1, 2, 4, 8 total steps at every t (Δt = t/n)
Log-log study
T = 4, n = 1, 2, 4, 8, 16, 32, 64, 128; slope from a least-squares fit of log(error) vs log(n) over the last 4 points
Trotter conventions (exact formulas so all teams build the same circuit)
First order: U₁(Δt) = e^(−iH_X Δt) · e^(−iH_ZZ Δt) — in the circuit the ZZ layer comes first, then the X layer.
Second order (bonus): U₂(Δt) = e^(−iH_X Δt/2) · e^(−iH_ZZ Δt) · e^(−iH_X Δt/2).
Gates: e^(+iJΔt ZᵢZⱼ) = RZZ(−2JΔt) and e^(+igΔt Xᵢ) = RX(−2gΔt). Bonds: even bonds (0,1), (2,3) first, then odd bond (1,2).
trotter_circuit(N, J, g, t, n, order, zz_mode) implements exactly this; your own implementation must match its statevector.
Observables
Observable
Definition
First-site magnetization
⟨Z₀(t)⟩
Staggered magnetization
M_s(t) = (1/N) Σᵢ (−1)ⁱ ⟨Zᵢ(t)⟩ (equals 1 at t = 0)
Loschmidt echo (optional)
|⟨ψ(0)|ψ(t)⟩|², free from the statevector
Tasks
Curves. For n = 1, 2, 4, 8 (first order), plot ⟨Z₀⟩ and M_s against t with the exact curve, and report the absolute error at every t and its maximum (s2_curves.csv).
Log-log error. At T = 4 compute the Trotter state error for every n in the log-log list, plot log-log, and report the fitted slope (s2_loglog.csv). Explain the value you expect and the one you measure.
ZZ construction. Build the ZZ term as CX–RZ–CX and as one RZZ gate. Report two-qubit gates and depth per Trotter step on Processors A, B and D, and on a Processor D variant with the rzz basis (s2_zz.csv). Explain when RZZ saves gates and when it does not.
Noisy check on D. For n = 4 and n = 8 at t = 4, measure ⟨Z₀⟩ and M_s with 4,096 shots, ideal and noisy on Processor D.
Architecture. Report resource metrics on A, B and D for one Trotter step and for the n = 8, t = 4 circuit.
Bonus: second-order Suzuki
Repeat the log-log study with second order and plot both orders together. The slope should change from about −1 to about −2; explain why, and compare the gate cost of each order at equal accuracy.

10. PS-S3 — Trotter error versus noise: finding the best step count
Problem
More Trotter steps reduce the algorithmic error, but every step adds gates and therefore noise. Under a fixed noise model there is a best number of steps n*. The headline deliverable is to find n* and explain it, and to show how it moves with noise strength and with processor connectivity.
Locked data
Item
Value
Hamiltonian
Ring, N = 4, J = 1, g = 1 (data/s3/tfim_ring_N4_g1.00.json), bonds (0,1), (1,2), (2,3), (3,0)
Initial state, time
Néel 1010; evolve to T = 2.0
Trotter
First order, convention of Section 9; bonds: even (0,1), (2,3) then odd (1,2), (3,0)
Step counts
n = 1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 14, 16
Noise scales
0.5×, 1×, 2× all three official rates (sweep on Processor D)
Tasks
Exact reference. Compute |ψ_exact(T)⟩ and M_s(T).
Step scan (headline). For every n, on Processors A, B and D at 1× noise, compute the noisy density-matrix fidelity F(n) (noisy_state_fidelity(), required) and M_s from 4,096 noisy shots. Find n* = the n with the highest F (smallest n on ties) for each processor (s3_scan.csv, s3_summary.csv).
Explain the crossover. Plot F(n) together with the noise-free Trotter fidelity, and explain why F rises then falls.
Noise sweep. On Processor D, repeat the scan at 0.5× and 2× noise and show how n* moves.
Gate split. For every circuit, split the two-qubit gate count into logical Trotter gates and routing gates added by SWAPs. Relate the loss of fidelity to each, and explain why the ring is harder on some processors.
Bonus: error mitigation
Apply one method — readout-error correction or zero-noise extrapolation — to M_s at n* on Processor D, and report the raw value, the mitigated value and the extra shots or circuits used (mitigation.csv).

13. Frequently asked questions
Question
Answer
Why is S3 on a ring when S1 and S2 are open chains?
On an open chain of 4 qubits every processor has a matching line, so no SWAPs are needed. The ring needs a 4-qubit cycle, which Processor A does not have, so connectivity becomes part of the result.
Can we use QPE in PS-S1?
No. PS-S1 is VQE only.
Our VQE gives a non-zero ⟨σz⟩. Is that wrong?
The exact value is 0. A non-zero value means your ansatz broke the spin-flip symmetry; report it and explain it rather than hiding it.
At g = 0.25 our energy is almost exact but the fidelity is about 0.5.
Expected when E₀ and E₁ are nearly degenerate. Report F₂ as well.
Does RZZ always save gates?
Only on a processor whose native basis contains RZZ. On a CX or CZ basis an RZZ gate is compiled into two two-qubit gates.
Can we use PauliEvolutionGate or Qiskit's Trotter classes?
Yes, if the resulting statevector matches trotter_circuit() for the official convention (check it).
Is Processor C used?
No. Phase 2 uses Processors A, B and D.
Can we use real IBM hardware?
Not for required runs. Everything runs on the local Aer simulator.
